# Amazon Homepage Clone

A front-end practice project that recreates the look and layout of an Amazon-style shopping homepage using **HTML and CSS**. It includes a navigation bar, search area, category panels, product sections, recommendations, and a multi-section footer.

## Features

- Amazon-style top navigation bar with logo, delivery location, search bar, language selector, account links, and cart.
- Secondary navigation panel with shopping links.
- Hero banner with a promotional message.
- Shopping category cards and product image grids.
- Personalized recommendations and sign-in section.
- Footer with company information, payment/language options, useful links, and copyright text.
- Font Awesome icons and flag-icons for interface icons.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Flag Icons

## Project Structure

```text
Amazon-Homepage-Clone/
├── index.html
├── style.css
├── amazon_logo.png
├── hero_image.jpg
├── 1.jpg ... 16.jpg
├── 1_style.avif ... 5_style.avif
└── other image assets used by the page
```

Keep the image files in the same locations referenced by the HTML and CSS. If an image is moved or renamed, update its file path in the code.

## How to Run

1. Download or clone this repository.
2. Make sure `index.html`, `style.css`, and all referenced image files are in the correct locations.
3. Open `index.html` in your web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension.

## Note

This is a front-end practice clone for learning HTML and CSS. It is not an official Amazon website. Some links are placeholders (`#`), and the page does not include real shopping, login, or payment functionality.
